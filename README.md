# Himalayan_Datawarehouse_Project

Welcome to this project repository
This project presents a comprehensive data warehousing and analytics solution designed to support mountaineering expeditions in the Nepalese Himalaya. It encompasses the end to end process of building a modern data warehouse, implementing robust ETL pipelines, applying advanced data modeling techniques, and delivering actionable insights through sophisticated analytics. The work underscores industry best practices in data engineering and analytics, demonstrating both technical rigor and practical applicability

-------------

## **Project Requirements**
### building the Data Warehouse (Data Engineering)

## **Objective**
Develop a moderate data warehouse using SQL Server to consolidate expedition data, enabling analytical reporting  and informed decision making

#### Specifications
- **Data Sources** | Importing data from system (Himalayan Expedition) provided as CSV files.
- **Data Quality** | Cleaning and resolving data quality issues prior to analysis
- **Integration** | combine data sources into a single, user friendly data model designed for analytical queries
- **Scope** | Focus on both latest and historical data
- **Documentation** | Provide clear documentation of the data model to support both business stake holders and analytics teams

-----------------------

# **BI: Analytics & Reporting (Data Analytics)**
#### Obejectives

Develop SQL-based analytics to deliver detailed insights into:
- **Peaks Behavior**
- **Successful Expedition**
- **Climbing Trends**
- **Climbing Performance**

These insights empower stakeholder by providing visibility into peak accessibility, expedition success, climber achievements, and long‑term mountaineering trends in the Nepalese Himalaya.
